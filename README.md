# 漫途集

漫行旅途，定制你的出行计划。

这是一个北京旅游路线定制网站。用户可以选择景点、美食、商场和民俗体验，输入游玩天数，再根据区域、停留时间和地点距离生成尽量少走回头路的行程。

## 当前内容

- 北京 206 张旅行卡片
- 景点、美食、商场、民俗四个分类
- 搜索与分类筛选
- 心愿单与旅行天数
- 自动生成多日路线
- 桌面、平板和手机响应式布局

## 本地运行

在项目根目录启动任意静态服务器，并把网站根目录指向 `dist`：

```powershell
python -m http.server 8787 --directory dist
```

打开 `http://127.0.0.1:8787/`。

## 部署

推送到 `main` 分支后，GitHub Actions 会自动把 `dist` 发布到 GitHub Pages。
